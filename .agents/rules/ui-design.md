# UI Design Rule

For frontend UI work:

- Read `GUIDED_MODE_DESIGN.md` before making visual changes.
- Treat its Royal Mineral Visual Design System as the visual source of truth.
- Preserve existing functionality, APIs, routes, calculations, state and data.
- Prefer existing components and centralized tokens.
- Do not introduce unrelated colors or visual styles.
- Do not use neon, rainbow palettes, generic green sustainability styling,
  excessive glassmorphism, or excessive gradients.
- Keep neutral surfaces dominant.
- AI = Amethyst/Plum.
- Metallurgy/material = Copper.
- Circularity = Jade.
- Premium emphasis = Champagne Gold.
- Inspect existing implementation before modifying it.
- Make the smallest safe set of changes.
- Verify the affected UI after implementation.
